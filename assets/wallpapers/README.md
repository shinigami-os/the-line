# The Line's wallpapers

Shipped with The Line, installed in `/usr/share/the-line/assets/wallpapers/`. Settings > Appearance lists them first,
before Kira's (`/usr/share/kira/wallpapers`) and yours (`~/Pictures/Wallpapers`, `~/.local/share/wallpapers`).

PNG, JPG or WebP, 3840 × 2160 (16:9) so they stay sharp on every screen. Keep the top 60 px calm (the line and its
tiles sit there) and the bottom-left corner dark (Kira's voice writes there).
